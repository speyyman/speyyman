# Saeed Peyman

Independent software and data engineer in Nashville. I build small, careful tools, study messy data, and make images and films from code. Site: [speyyman.github.io](https://speyyman.github.io).

## Things you can use

- [plate-engine](https://github.com/speyyman/plate-engine): procedural engravings and dithering in TypeScript, with Plate Studio for e-paper images. `npm install plate-engine`
- [chladni](https://github.com/speyyman/chladni): plate physics that draws Chladni figures in sand, with a [browser demo](https://speyyman.github.io/chladni/).
- [second-brain-os](https://github.com/speyyman/second-brain-os): an Obsidian starter vault with an agent layer, and `vault-publish`, which shares chosen notes and refuses anything that looks private.
- [engravings-film](https://github.com/speyyman/engravings-film): the render script behind the film "Engravings, drawn live".
